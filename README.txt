HOW TO GET THE APK (no computer software needed)
1. On github.com create a NEW repository (e.g. shop-debts-apk). Upload ALL files and folders from this zip
   (including the hidden ".github" folder - on a phone/PC use "Add file > Upload files" and drag the whole folder).
2. Open the repository > Actions tab > "Build Android APK" > Run workflow. Wait ~5-8 minutes.
3. Open the finished run > Artifacts > download "ShopDebts-APK" > unzip > app-debug.apk.
4. Copy it to the phone, tap it, allow "install unknown apps". Open once. Works fully offline.
Your old data does NOT move automatically: Export Backup in the old app, then Restore Backup in this one.
